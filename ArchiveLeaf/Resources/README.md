## App icon

`Assets.xcassets/AppIcon.appiconset/ArchiveLeaf-AppIcon-1024.png` is the project master. Smaller macOS representations are independently downsampled from the original generated artwork rather than from one another.

The icon was created with the built-in ImageGen tool on 2026-08-04. The production prompt requested a centered, text-free, fully opaque Apple-platform icon combining one bright leaf with a compact archive box, using a forest-green and muted-cream palette, generous safe padding, a crisp small-size silhouette, and no rounded outer corners or border. The output was checked at 16 px, 32 px, compiled macOS 256 px, and compiled iOS 120 px.
